# Contributing

Thank you for your interest in improving this project.

We welcome contributions that improve the accuracy, usability, and documentation of the calculators.

## Ways to Contribute

- Report calculation errors
- Suggest new calculator features
- Improve documentation
- Fix UI issues
- Improve accessibility
- Improve mobile responsiveness

## Reporting Issues

Before opening an issue, please check if it has already been reported.

When reporting an issue include:

- Calculator name
- Expected result
- Actual result
- Browser
- Device

## Pull Requests

Please keep pull requests focused on a single improvement.

Examples:

- Bug fixes
- Formula improvements
- UI improvements
- Documentation updates

Thank you for helping improve retirement planning resources for everyone.
