# Financial Formulas

This project uses standard financial formulas commonly applied in investment and retirement planning.

## Future Value (FV)

Future Value estimates the value of regular investments after compound growth.

Factors considered:

- Monthly investment
- Annual rate of return
- Investment duration
- Compounding frequency

## Retirement Corpus

Corpus calculations estimate total savings accumulated by retirement.

## Pension Estimation

Estimated monthly pension is calculated using selected annuity assumptions.

The formulas are intended for educational purposes only.
