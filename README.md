# NPS Calculators

A free collection of National Pension System (NPS) calculators and retirement planning tools built for Indian investors.

The goal of this project is to make retirement planning easier by providing simple, accurate, and easy-to-use calculators based on publicly available NPS rules and formulas.

## 🌐 Live Website

https://npscalculators.in/

## Features

- NPS Calculator
- NPS Return Calculator
- NPS Pension Calculator
- NPS Tier 1 vs Tier 2 Calculator
- Retirement Corpus Calculator
- Monthly Pension Estimator
- Tax Savings Calculator
- Inflation Adjusted Retirement Calculator
- Step-up Investment Calculator
- Financial planning resources

## Why this project?

Planning retirement can be confusing because there are many variables, including:

- Monthly contribution
- Expected annual return
- Retirement age
- Inflation
- Pension withdrawal
- Tax benefits

This project simplifies these calculations into easy-to-use online tools.
